# tech-demos

A collection of JavaScript demos.

## Demos

- [Peekaboo Bots](apps/peekaboo-bots/) — A playful gallery of Grok Bot avatar shapes. Click any bot to play peekaboo.
- [Student Profile Rubric Builder](apps/jev-student-profile/) — Author a Choice/Score/Noul rubric, evaluate a student, or batch-run the full rubric on 100 students with TypeSafe Jev (English and Simplified Chinese).
- [Admissions Triage](apps/jev-admissions-triage/) — Sort 100 fabricated applications by Jev attention, then inspect calibrated field verdicts.
